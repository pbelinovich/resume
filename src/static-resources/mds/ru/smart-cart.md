## Обзор проекта

Smart Cart Bot — это AI-powered Telegram бот для сравнения цен в продуктовых магазинах. На данный момент это единственный сервис, способный найти самый дешевый или популярный продукт просто по строке пользователя, автоматически сравнивая цены в различных ритейлерах и собирая оптимальные корзины.

**ЦЕЛЬ**

Создать полностью бесплатный сервис, который помогает пользователям найти самые дешевые продукты и собрать оптимальные корзины без ручного сравнения цен в разных магазинах.

**ОСОБЕННОСТИ**

• AI-парсинг естественного языка в структурированные JSON данные

• Автоматическое сравнение цен в множественных ритейлерах (Пятёрочка, Магнит, Дикси, Перекрёсток)

• Интеллектуальное формирование корзин с оптимальным выбором цен

• Легкая замена товаров в собранных корзинах

• Поддержка нескольких городов с автоматическим обновлением цен

• Предотвращение импульсивных покупок через сфокусированный интерфейс

## Демонстрация функционала

### Базовый флоу

Полный пользовательский путь от команды /start до получения оптимизированных корзин с сравнением цен

---

### Фильтрация по категориям

Умное понимание категорий товаров - бот может применить категорию ко всем товарам или к каким-то отдельным

---

### Смена города

Динамическое переключение городов с автоматическим обновлением цен и изменением доступности ритейлеров

---

### Замена товара

Легкая замена товаров в собранных корзинах с пересчетом цен в реальном времени

---

## Архитектура системы

### Микросервисная архитектура

Приложение построено с использованием микросервисной архитектуры с четким разделением ответственности между слоями обработки данных и взаимодействия с пользователем

**BACKEND СЕРВИС**

Независимый сервис обработки данных, который может быть подключен к любой платформе (web, mobile, tg bot).

- Интеграция AI модели и инференс
- Интеграция API ритейлеров и обработка данных
- Алгоритмы сравнения цен
- Управление базой данных и кэширование
- REST API для внешних интеграций

**TELEGRAM BOT СЕРВИС**

Легковесный сервис, который выступает прослойкой между пользователями и бэкендом.

- Интеграция с Telegram Bot API
- Управление взаимодействием с пользователями
- Обработка и валидация сообщений
- Обновления статуса в реальном времени через SSE
- Обработка ошибок и обратная связь с пользователями

**МЕЖСЕРВИСНОЕ ВЗАИМОДЕЙСТВИЕ**

Общение между сервисами через REST API и Server-Sent Events (SSE) для мгновенных обновлений статуса.

- REST API для основных операций
- SSE для отслеживания статуса сборки корзин
- SSE для отслеживания смены города
- Трансляция статуса ошибок
- Отслеживание прогресса пользователя
- Бесшовная координация сервисов

**Технологии:** Node.js, TypeScript, Express, Telegraf, SSE, RavenDB

## AI/ML реализация

### Дообучение модели

Кастомное дообучение модели Mistral 7B со специализированным датасетом для распознавания и парсинга продуктовых товаров

- Сгенерировано 1500+ обучающих записей с помощью GPT-4
- LoRA (Low-Rank Adaptation) для эффективного дообучения
- Точность FP16 для оптимизации памяти
- Квантование Q4_K_M для совместимости с 12GB VRAM
- Специализированное обучение для распознавания яичных продуктов

**Технологии:** Mistral 7B, LoRA, Fine-tuning, Ollama

---

### Парсинг списка продуктов

Конвертация пользовательских сообщений в структурированные данные покупок

- Парсинг естественного языка в JSON
- Извлечение и нормализация названий товаров
- Распознавание количества и единиц измерения
- Классификация ценовых категорий

**Технологии:** JSON Parsing, NLP, Text Processing

---

### Оптимизация производительности

Множественные техники оптимизации для обеспечения быстрого и эффективного AI инференса на потребительском железе

- Квантование модели для уменьшения использования памяти
- Точность FP16 для ускорения инференса
- Интеграция с Ollama для локального обслуживания модели
- Стратегии кэширования для повторных запросов
- Реализация очередности запросов к модели

**Технологии:** Quantization, FP16, Q4_K_M
