## Личные проекты

### Smart Cart Bot

**AI-powered Telegram бот для автоматического сбора корзин в продуктовых магазинах**

[Подробнее →](/smart-cart)

AI-сервис для сравнения цен в ритейлерах и автоматической сборки оптимальных корзин на основе естественного языка.

#### 🎯 Ключевые особенности

**AI/ML реализация:**

- Fine-tuning Mistral 7B с собственным датасетом (1500+ записей, генерация через GPT-4)
- LoRA адаптация с квантованием Q4_K_M для работы на 12GB VRAM
- Парсинг естественного языка в структурированные данные (JSON) с распознаванием количества, единиц измерения и категорий

**Backend архитектура:**

- Микросервисная архитектура с разделением bot service и backend service
- Интеграция с маркетплейсом для получения данных о продуктах из различных ритейлеров
- SSE для real-time обновлений статуса сборки корзин и смены города
- REST API для возможности подключения web/mobile клиентов

**Bot реализация:**

- Интеграция с Telegram Bot API через Telegraf
- Автоматическое сравнение цен и формирование оптимальных корзин
- Поддержка нескольких городов с динамическим переключением
- Легкая замена товаров в собранных корзинах с пересчетом в реальном времени
- Моментальное обновление статуса сборки корзин через SSE

📱 [smartaicartbot](https://t.me/smartaicartbot)  
💻 [pbelinovich/smart-cart](https://github.com/pbelinovich/smart-cart)

**Технологии:** `Node.js` `TypeScript` `Express` `RavenDB` `Mistral 7B` `LoRA` `Ollama` `Telegraf` `Telegram Bot API` `SSE` `Docker`
