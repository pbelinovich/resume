## Основные проекты

### ИС региональной сети пиццерий «HANS»

Комплексная информационная система управления сетью пиццерий, аналог системы Додо Пиццы.

**ЦЕЛЬ ПРОЕКТА**

Создать полноценную информационную систему для управления всеми процессами региональной сети пиццерий: от приема заказов до доставки готовой продукции клиентам.

**ФУНКЦИОНАЛЬНОСТЬ**

- Система приема и обработки заказов от клиентов
- Панель управления для поваров с отслеживанием готовности блюд
- Модуль для курьеров с маршрутизацией доставки
- Административная панель для управляющих
- Система формирования и отслеживания заказов в реальном времени
- Логистическая система управления доставкой
- Интеграция с CRM и системами учета

**РОЛЬ В ПРОЕКТЕ**

- Разработка пользовательских интерфейсов для всех ролей системы
- Интеграция с 1С-Битрикс CMS для управления контентом
- Создание адаптивных и кроссбраузерных решений
- Работа с базами данных и API интеграциями

**Технологии:** 1С-Битрикс, jQuery, HTML/CSS, JavaScript, MySQL

---

### Мобильное приложение «Госуслуги ХМАО»

Региональное мобильное приложение государственных услуг для жителей Ханты-Мансийского автономного округа.

**ОПИСАНИЕ ПРОЕКТА**

Разработка кроссплатформенного мобильного приложения для предоставления государственных услуг жителям ХМАО. Приложение обеспечивало доступ к региональным госуслугам через удобный мобильный интерфейс.

**ФУНКЦИОНАЛЬНОСТЬ**

- Авторизация через единую систему идентификации
- Каталог доступных государственных услуг
- Подача заявлений и документов
- Отслеживание статуса обращений
- Уведомления о готовности документов
- Интеграция с региональными информационными системами

**ТЕХНИЧЕСКИЕ ОСОБЕННОСТИ**

- Кроссплатформенная разработка для iOS и Android
- Использование гибридных технологий для быстрой разработки
- Адаптивный UI с нативным look & feel
- Оптимизация производительности для старых устройств
- Безопасное хранение пользовательских данных

**Технологии:** Backbone.js, Underscore.js, Cordova, Framework7, HTML/CSS, JavaScript
