## CMS Система «CODELESS»

### Разработка редактора выражений для CODELESS

Инновационный редактор кода с DOM-архитектурой и полной типизацией.

**ЦЕЛЬ**

Создать инструмент для написания псевдокода (похожего на JavaScript), который в последствии будет интерпретирован в JavaScript и затем выполняться на клиенте. Написание кода необходимо при создании проектов CODELESS. Данный инструмент должен ускорять процесс создания проектов.

**ОСОБЕННОСТИ**

- Генерация умных подсказок при написании кода
- Полная валидация ошибок в реальном времени
- Использование DOM-элементов вместо текстового представления
- Особое внимание к производительности
- Полная типизация и пробрасывание контекста
- Адаптивность под различные экраны
- Масштабирование шрифта
- Полноценная поддержка Copy/Cut/Paste операций

**ВАЛИДАЦИЯ ОШИБОК**

- Валидация синтаксиса в реальном времени
- Подсветка ошибочных участков кода
- Детальные сообщения об ошибках
- Проверка типов и контекста

**DOM-АРХИТЕКТУРА**

- Полный отказ от текстового представления
- Каждый элемент - отдельный DOM-элемент
- Интерактивные элементы управления
- Сложная система управления фокусом

**ТИПИЗАЦИЯ**

- TypeScript типизация на всех уровнях
- Автоматическое определение типов
- Контекстные подсказки
- Проверка совместимости типов

**ОПТИМИЗАЦИЯ**

- Система рендеринга "только того, что нужно"
- Система вычисления форматирования элементов кода (+ кэширование)
- Мемоизация вычислений

**Технологии:** React, TypeScript

### Миграция с файловой системы на RavenDB

Комплексная миграция архитектуры для решения проблем производительности и масштабируемости.

**ПРОБЛЕМА**

Предыдущая архитектура хранила конфиги проектов в JSON файлах, что вызывало проблемы с производительностью при работе с большими проектами. Память быстро заполнялась, скорость записи/чтения была неоптимальной.

**РЕШЕНИЕ**

Совместно с техническим директором принято решение о миграции на RavenDB (NoSQL с поддержкой транзакций из коробки). Принимал участие в переезде и переписании бэкенда с нуля.

**ВЫПОЛНЕНО**

- Полная миграция с файловой системы на RavenDB
- Переписывание backend архитектуры
- Реализация транзакционной системы
- Оптимизация производительности и памяти
- Масштабируемая архитектура для больших проектов

**Технологии:** Node.js, RavenDB, Express, TypeScript

### Система автоматического запуска "подов"

Автоматизация развертывания и управления отдельными экземплярами проектов.

**ПРОБЛЕМА**

DevOps настраивал серверы вручную для каждой версии проекта и прописывал правила в nginx конфиге. Процесс был медленным и подверженным ошибкам.

**РЕШЕНИЕ**

Разработка системы автоматического создания и запуска отдельных дочерних процессов в Node.js с автоматическим управлением портами и прокси.

**ВЫПОЛНЕНО**

- Автоматическое создание и запуск отдельных дочерних процессов в Node.js
- Для каждой версии проекта поднимается отдельный сервер по уникальному порту
- Пользователь получает ссылку с портом и видит реальное рабочее приложение (билд конфига)
- Разработал систему настройки прокси для каждого пода (перенаправление, смена заголовков, HTTP/WS соединения, таймауты, правила замены путей)

**Технологии:** Node.js, Child Processes, Express, Proxy, TypeScript

### SSE Коммуникатор

Система типизированного взаимодействия клиент-сервер с использованием Server-Sent Events.

**ПРОБЛЕМА**

Необходимость в прозрачном и типизированном API взаимодействии между клиентом и сервером с поддержкой real-time обновлений.

**РЕШЕНИЕ**

Создание SSE коммуникатора с использованием Proxy класса в Node.js для скрытия адресов HTTP методов и полной типизации API.

**ВЫПОЛНЕНО**

- Технология: Server-Sent Events (SSE)
- Архитектура: TypeScript типизированные HTTP методы (GET, POST, Channel)
- Фишка: Использование Proxy класса в Node.js для скрытия адресов HTTP методов
- Синтаксис: await protectedApiClient.user.GET.byId({ id: "123" })
- Преимущества: Прозрачное взаимодействие клиент-сервер с полной типизацией

**Технологии:** TypeScript, Server-Sent Events, Node.js, Proxy API
